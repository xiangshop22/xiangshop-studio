# 效果工坊 v62.0

**第一次使用：** 下载 [full/EffectStudio-full.zip](full/EffectStudio-full.zip)，解压后双击 `start.bat`。

**已经在用：** 打开工作台，点左上角「检查更新」，勾选后自动下载安装，不用手动下载。

- 工作台版本：v62.0
- 效果数量：58
- 发布时间：2026-11-26
- 本次更新：· 「镜头推进·焦点转移」的背景改成四种：图片 / 文字 / 视频 / 时间线素材。去掉了「不要背景」和「纯背景样式」两个按钮：图片不上传就是透明背景（和以前「不要背景」一样）；老工程里用了纯背景样式的照常显示、照常能改。
· 背景选「文字」：写一段字当背景（能改字号、颜色、上中下位置、字后面压暗），开场模糊偏暗，推完变清楚变亮；也能在预览里双击这段字直接改。
· 背景选「视频」：上传一段视频当背景，同样开场模糊、推完清楚，跟着镜头一起放大。
· 嵌在里面的素材比外面那条晚结束时，外面那条自动拉长到一样长（旗子不动，多出来的时间加在「停」后面）；只拉长、不缩短。
· 点「🎯 拾取」后鼠标变成 🎯 图标（以前那个螺旋图标没显示出来），鼠标移到预览、时间线上也都是 🎯；点到素材或按 Esc 恢复。

这个仓库由「发布更新.bat」自动生成，请不要手动修改里面的文件。
